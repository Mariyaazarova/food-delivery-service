# Сервис онлайн заказа еды из ресторанов

## Описание проекта

Проект представяет собой учебное веб-приложение, позволяющее пользователям удобно искать рестораны и заказывать еду онлайн. Приложение создано с использованием современных технологий: React, Redux, React Router и Vite.

## Функционал

- **Поиск ресторанов:** Пользователи могут находить рестораны по названию, типу кухни или местоположению.
- **Просмотр меню:** Возможность просматривать детальное меню каждого ресторана с описанием блюд и ценами.
- **Оформление заказа:** Пользователи могут добавлять блюда в корзину и оформлять заказы.
- **Отзывы:** Пользователи могут оставлять и редактировать отзывы о ресторанах и блюдах.
- **Смена темы:** Возможность переключения между светлой и темной темой интерфейса.

## Технологии

- **Frontend:** React, Redux, React Router, Vite.
- **CSS Framework:** CoreUI.
